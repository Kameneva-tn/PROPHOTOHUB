# PROPHOTOHUB — оновлення (мобільна версія + єдина шапка)

Залийте всі файли з цієї папки в репозиторій PROPHOTOHUB поверх наявних
(Add file → Upload files, структура папок збігається).

Що змінено:

index.html                 — спільна шапка PROPHOTO з бургер-меню замість старого меню
halls/*.html               — те саме для трьох сторінок залів
js/prophoto-nav.js         — новий файл: шапка + бургер-меню (після прокрутки стає чорною)
js/main.js                 — календар: 7 днів на телефоні / 14 на десктопі, гортання стрілками;
                             паралакс фото залів вимкнено на тачах, на десктопі — без смикання
css/style.css              — календар уміщається в екран телефона; кнопка «подзвонити» — рівне коло;
                             якорі не ховаються під шапкою
public/assets/hero-logo-transparent.png — логотип без напису «hub»
public/assets/hero-bg.jpg  — нове фото головного екрана (панорама циклорами)
public/assets/hero-bg-mobile.jpg — вертикальний кроп того ж фото для телефонів
admin.html                 — сторінка керування бронюваннями (див. README-ADMIN.md)

Після завантаження зачекайте 1–2 хв і відкрийте сайт у приватній вкладці (щоб не показувався кеш).
