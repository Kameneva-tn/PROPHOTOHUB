# Адмінка бронювань

Файл `admin.html` — залити в корінь репозиторію PROPHOTOHUB.
Адреса: https://kameneva-tn.github.io/PROPHOTOHUB/admin.html
(посилання ніде на сайті не показується, для пошуковиків закрита)

Вхід — пароль ADMIN_TOKEN, заданий у налаштуваннях сервера на Render.

Що вміє:
- список бронювань за період (сьогодні / 7 / 30 днів / свій діапазон), фільтр по залах
- скасувати одну годину (× біля години) або всі години клієнта одразу
- показати скасовані (галочка) — з причиною
- зайняти години вручну: техперерва, власна зйомка, бронь по телефону
- телефон клієнта клікабельний — дзвінок з телефону в один тап

Працює на телефоні.
